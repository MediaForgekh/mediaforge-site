# MediaForge website

**Save. Convert. Organize.** The public site for the MediaForge desktop app, plus every release's installers.

- Site: https://mediaforgekh.github.io/mediaforge-site/
- Downloads: [GitHub Releases](https://github.com/MediaForgekh/mediaforge-site/releases)

This repository is **generated**. The site is a static export of `mediaforge-web` (`bun run generate:site`), and the installers are published by `mediaforge-desktop/scripts/publish-release.sh`. Don't edit the files here by hand.
